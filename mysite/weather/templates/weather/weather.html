Weather Forecast Analysis

How it works

This project is a weather forecast accuracy tracker that compares {{api_count}} weather APIs to determine which provides the most reliable predictions.

Data Collection: An automated hourly task collects forecasts from each weather provider for {{location_count}} U.S. cities. Current weather data is pivoted against prior forecasts.
Analysis & Visualization: The pivoted data is analyzed to determine accuracy and generate the charts below.
Scale: The database currently contains {{forecastcount}} individual forecast records, with new forecasts added each hour.
Tech Stack: Forecast collection and analysis is a blend of Python and SQL. The site is written in Django with a Bootstrap frontend.

Pivot Version

When I originally built this project, I worked under the assumption that weather APIs were always correct for the current hour. So I compared forecasts against the same APIs data.

Once I started incorporating precipitation data, I realized that the current hour's precipitation value is still a forecast, not observed data. Forecast Pivot v2 fixes this by using Google's historical weather API to compare forecasts against the previous hours observed temperature and precipitation.
